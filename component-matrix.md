# AdminLTE 3 Component-Use Matrix

| # | Component | Screen | Purpose | Related Data / Task |
|---|---|---|---|---|
| 1 | **Small Boxes / Info Boxes** | Dashboard | Display high-level counts and metrics at a glance[cite: 4] | Total Appointments Today, Pending Bookings, Active Staff |
| 2 | **DataTables (Responsive Table)** | Appointment List | List all scheduled bookings with sorting and filter features | Client name, service type, date, time, and status |
| 3 | **Forms & Input Groups** | New Appointment Screen | Provide clean fields to collect appointment parameters | Customer dropdown, Date/Time picker, Service selector |
| 4 | **Badges** | Appointment List / Dashboard | Show color-coded status highlights (e.g., Yellow for Pending, Green for Confirmed)[cite: 4] | Appointment status field |
| 5 | **Cards / Box Widgets** | Dashboard | Group layout sections into clean visual containers | Grouping summary charts or upcoming schedule blocks |
| 6 | **Alerts / Callouts** | New Appointment Screen | Display warning alerts if a booking slot conflicts with existing schedules[cite: 4] | Notification for double-booking or scheduling conflicts |
| 7 | **Buttons & Button Groups** | All Screens | Standardize primary actions across views[cite: 4] | "Book Appointment", "Edit", "Cancel", or "Approve" |
| 8 | **Breadcrumbs** | All Screens | Provide clean structural path context at the top of pages[cite: 4] | Home > Appointments > Schedule List |
